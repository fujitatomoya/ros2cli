Changelog for package ros2log
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

0.40.4 (2025-01-09)
-------------------
* Initial release of ros2log package
* Implemented 'ros2 log watch' command with filtering options:
  - Level filtering (DEBUG, INFO, WARN, ERROR, FATAL)
  - Logger name filtering
  - Regular expression pattern matching
  - Colorized output (can be disabled)
  - Timestamp display (can be disabled)
  - Function detail display (file, function, line number)
* Contributors: Tomoya Fujita, Fumiya Ohnishi
